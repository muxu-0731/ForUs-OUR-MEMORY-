## 📖 关于项目
ForUs（献给我们）是一款纯个人情怀制作的2D像素回合制独立游戏。

这不是商业作品，没有盈利目的，只是我为自己、为挚友、为我们曾并肩走过的时光，写下的一份温柔纪念。
游戏里的每一个角色、每一场战斗、每一段旅途，都是留给回忆的载体。

---

## 🎮 游戏简介
- **类型**：2D像素风格 · 回合制战斗RPG
- **开发**：个人独立开发（Godot + C#）
- **内容**：原创角色体系、多角色专属技能与被动、渐进式敌人战斗流程
- **初心**：以此作，献给永远的我们
